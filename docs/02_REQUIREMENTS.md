# Lowpoly Character Maker — 要件定義（うのっち承認済み）

初版: PC向け、ブラウザ単一画面、スマートフォン対象外。リグ／アニメーションは将来アップデートの候補でありP0には含めない。

参照: [概要](01_OVERVIEW.md)。仕様を増やす場合は、Issueだけを変更せずここへ戻して承認を取る。

## ユーザージャーニー

1. 起動時に見本キャラと「再抽選」「GLBを書き出す」が見える。
2. パーツを選んで外観がすぐ変わる。色は定義済みの小さなパレットから選べる。
3. 任意の部位を固定し、再抽選で非固定部位だけが変わる。全体再抽選・固定解除も可能。
4. 画面で三角形数／256、使用色数／8、シードを確認する。
5. GLBを保存し、外部のGLBビューア等で形と色が再現される。

## P0 必須（初版）

- R1: 文字入力やログインなしで、少なくとも1つのキャラが起動直後に表示される。
- R2: 1つの共通人型素体に対し、髪・服・小物の各部位で複数の独自パーツ候補を選べる。各候補と組合せは制約内で出力可能なものだけを提供する。
- R3: 再抽選は固定中の部位を変えない。同じシードと同じ選択・固定状態なら同じ結果を再現できる。別のシードでは複数の異なる有効な結果が出る。
- R4: 表示される三角形数は**出力される全メッシュを三角化した実数**と一致し、256以下。非表示メッシュや小物も出力されるなら加算する。
- R5: 色数は出力に使われる相異なるベース色（不透明RGB）の数と一致し、8以下。照明による画面上の陰影は数えない。テクスチャ・透明・頂点色は初版では使わない。
- R6: 出力は1つのGLBファイル。プレビューと同じ部位・パレット色・静止ポーズで表示される。ダウンロードにアカウントやAPIキーを要求しない。
- R7: 制約違反、組合せ不能、書き出し失敗時は破損したGLBを出さず、原因と回復操作を表示する。
- R8: 固定・選択・再抽選・出力がマウスとキーボードで利用できる。3D表示が使えない環境でもエラーと代替説明を示す。

## 検証可能な完了条件

- 見本と、全固定・一部固定・固定なしの各操作で期待どおりの再抽選ができる。
- 提供する**全パーツ組合せ**（計算量が大きければ各候補＋境界ケースと生成プロパティ）で、エクスポート前後の三角形数≤256、色数≤8、表示値の一致を機械検査する。
- GLBを独立したローダーで再インポートして、GLB構造、形状の存在、部位と色の一致を検査する。単にファイルがダウンロードできただけでは合格としない。
- PCの通常のデスクトップブラウザで最初の表示→固定→再抽選→書き出しを実操作で確認する。スマートフォン／タッチ編集は対象外。
- READMEに起動方法・操作方法・制約の数え方・既知の制限を記載する。

## P1 候補（P0完了後に再審査）

保存／読み込み用の短いシード共有、別体型、表情、ポーズ、**リグ／アニメーション対応**、色覚配慮したパレット。リグ／アニメーションは将来アップデートの方向だが、P0には混ぜず、P0のGLBをリグ済みと表示しない。

## 非目標

既存ゲームのキャラ再現、既存ゲームのモデルやテクスチャの取り込み、生成AI API、クラウドDB、ユーザー登録、ソーシャル投稿機能、一般的なフル機能モデラー。

## 実装前に凍結する詳細

- パーツ候補の具体的な個数とデザイン方向。256三角形で成立するものを実測し、承認済みP0の範囲で凍結する。候補追加でP0の意味が変わる場合は再レビューする。
