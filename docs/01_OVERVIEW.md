# Lowpoly Character Maker — 概要（うのっち承認済み）

承認事項: 初版はPC向け・ブラウザで動く単一画面アプリ。スマートフォンは対象外。将来アップデートでリグとアニメーションに対応する（初版の実装範囲には含めない）。

## 目的

選択と部分再抽選だけで、移動シーンを連想させるデフォルメされた**オリジナル**の低ポリゴン人型キャラクターを作り、静止GLBとして持ち出せる小さなアプリ。3D制作の初見の怖さを下げ、Unity・Blender・個人制作で「自分のキャラを使えそう」と思える入口を作る。

## 体験の核

1. キャラクターが最初から画面に見えている。
2. 髪型・服・小物と色を選ぶ。または再抽選で候補を出す。
3. 気に入った部分を固定して、残りだけ再抽選する。
4. 完成キャラ全体の三角形数と使用色数を確認し、GLBをダウンロードする。

入力文字列やプロンプトを書かなくても成立する。「選択した手応え」と「意外な組み合わせ」の両立が狙い。

## 固定された制約

- 完成キャラの出力メッシュ全体で**三角形256枚以下、使用色8色以下**。四角面数では数えない。
- 初版の出力は**静止ポーズのGLB**。リグ・アニメーションは初版に含めない。
- 引用した画像は雰囲気の参考であり、既存ゲームの固有キャラクター、名称、衣装、テクスチャ、ロゴ、アセットを再現・流用しない。公開名はオリジナル名にする。

## POCの境界（承認済み）

- PC向け・ブラウザで動く単一画面のローカル完結アプリ（サーバー・ログイン・生成AI APIなし）とする。スマートフォンは対象外。
- 人型の共通素体1つ、交換可能な髪・服・小物の少数プリセット、色選択、シード付き再抽選、部位固定、3Dプレビュー、GLB出力。
- 特定のFF作品に寄せたプリセットや実在キャラの再現を提供しない。
- 別の体型、顔の詳細編集、表情、骨格・アニメーション、公開ギャラリー、クラウド保存、AIテキスト生成は後続へ分離する。

## 成功の見え方

初見の人が入力文なしでパーツを選び、気に入った髪を固定して他を再抽選し、予算内のオリジナルキャラをGLBで取り出せる。再インポートしても形と色が保持される。
