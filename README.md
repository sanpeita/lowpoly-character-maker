# lowpoly-character-maker

選択と部分再抽選でオリジナルの低ポリ人型キャラクターを作り、静止GLBへ書き出すアプリの企画です。

**現状:** うのっちが設計と「PC向けブラウザ単一画面／スマートフォン対象外／将来リグ・アニメーション対応」を承認。Solが[P0の実装Issueと将来Issue](docs/ISSUE_MAP.md)を作成済み。コード実装は未着手。

## 設計資料（承認済み）

1. [概要](docs/01_OVERVIEW.md) — 目的、体験、IP境界、POC範囲。
2. [要件定義](docs/02_REQUIREMENTS.md) — 操作、256三角形／8色、受け入れ条件。
3. [詳細設計](docs/03_DETAILED_DESIGN.md) — 責務、データ契約、検証、Issue化の種。

Solは文書とIssueの対応を作成済み。実装の技術選定・担当権限・独立レビューゲートは[#1](https://github.com/sanpeita/lowpoly-character-maker/issues/1)で凍結してからコーダー部隊へ引き渡します。未確定事項は要件定義・詳細設計の末尾に記載しています。
